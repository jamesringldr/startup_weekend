# Startup Weekend KU — Prework Repo

## The one-paragraph version
James is pitching a **sports-betting options exchange** Friday night: calls, puts, and spreads on games with a live bid/ask book, so bettors can enter *and exit* positions the way they'd trade a stock (USDC settlement). Betfair proved the model everywhere else; it blocks the US. The weekend builds a working demo of one league, one contract type, and pitches it Sunday in 3 minutes to five judges. Full vision and current state: **[JOURNAL.md](JOURNAL.md)** — read that first if you're a new agent picking this up.

## Rules that govern everything here
- **Track A ≠ Vanyshr.** Friday/Sunday pitches are the exchange. Vanyshr (James's actual company, consumer data privacy) is Track B — networking and follow-up only, never during judging.
- **Never say "billionaire maker."** Universal kill phrase on this panel. Also never: unfooted TAM, USDC/crypto as a regulation workaround, "disrupting gambling," or claiming the exchange is unregulated space.
- **Nothing sends, submits, or ships in James's name without his explicit word on that run.** No applications, no outreach, no posts, no production pushes.
- **Claims stay literal.** If a number isn't verified, say "I don't know yet." That honesty is a feature, not a gap.
- **James's persona for the weekend: "the operator who ships."** Plain, specific, fast. Numbers when he has them, "I don't know yet" when he doesn't. No superlatives about himself.
