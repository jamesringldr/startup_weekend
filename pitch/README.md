# Pitch — Index

## Formats (from the live event pages)
- **Friday — 60 seconds, event template, name required, no slides, props OK.** Register the pitch at the registration desk. Template shape: founder of X → audience struggles with Y → impact → product → benefit → team skills needed. Script: `friday-60s-pitch.md`.
- **Sunday — 3 minutes, hard stop + 2 minutes Q&A.** Slides must be **Google Slides**; the live demo must exist **in the slide** (primary: recorded demo video embedded; live demo is a stretch goal). One Slides link shared Day 2. **Slides freeze Sun 4:30pm; final pitches start 6:30pm.** Lean Canvas is the official framework.
- **If not selected Friday:** self-form a team of 4+ to run your own idea (15-team cap) — or join another team (see `join-team-strategy.md`).

## The rubric (five criteria, each scored 1–5)
1. **Customer Validation** — real customer conversations/data vs. alternatives.
2. **Team Dynamic** — complementary skills; **shared delivery across the team (1 = delivery by one person).**
3. **Business Model** — sustainable; **multiple revenue streams rewarded.**
4. **Execution & Design** — what you built, how feedback shaped it, demo/MVP.
5. **Impact** — who benefits, how widely.

## Sunday 3-minute structure (team relay, mapped to rubric order)
James opens — problem (~30s) → Validation lead — evidence (~35s) → Builder — demo (~35s) → Numbers — model, plural revenue streams (~35s) → James closes — impact as fairness/exit rights/transparency + staged regulatory path (~30s).
Q&A pre-assigned by topic: regulation + market math → James; validation follow-ups → validation lead; liquidity/demo → builder. Full bank: `q-and-a-prep.md`.

## Guardrails (from the judges recon)
- Never say "billionaire maker." Never: unfooted TAM, USDC/crypto as a regulation workaround, "disrupting gambling," claiming unregulated space.
- Never demo a trade on a KU game. Never Jayhawk imagery in betting graphics. Never pitch alumni networks as GTM.
- Winning Sunday order: plain-language story (Peterson) → validated problem (Bergman) → mechanics + market math that foots (Fein/Clarke) → staged regulated path (Courtney/Clarke) → Kansas close.
